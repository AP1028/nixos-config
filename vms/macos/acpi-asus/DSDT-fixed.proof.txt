### 7. note on the "5185 Objects" line printed by acpiexec 20160930
    acpiexec 20160930 prints that counter in the middle of AcpiNsLoadTable(),
    i.e. after pass 1 + pass 2 but *before* the module level code is executed.
    acpiexec 20260408 prints it in single pass mode, after module level code
    already ran, which is why the same table shows 5185 there and 5955 here.
    After full initialisation the two agree: 20160930 reports
      "Initialized 64/118 Regions 0/90 Fields 32/77 Buffers 75/102 Packages (5964 nodes)"
    and 20260408's namespace dump reports "Namespace node count: 5966"
    (the 2 extra nodes are ACPICA's internal _TI_/_T97 temporaries).
    No count regressed; 20260408 reports 5955 Objects / 190 Devices / 118 Regions
    / 978 Methods for both the original and the fixed table.
